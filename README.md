# NinjaValues v2

A redesigned static Ninjago minifigure value list built for GitHub Pages.

## Main feature
The season navigation is controlled by the `season` field in `js/figures.js`.

Example:
```js
{id:"example",name:"Example Figure",character:"Kai",season:"Season 1",year:2011,rarity:"Rare",demand:"High",value:50,trend:"rising",change:"+5%",note:"Description"}
```

Available demand levels:
Very Low, Low, Medium, High, Very High, Insane

Available trends:
rising, stable, dropping

Upload all files to a GitHub repository and enable GitHub Pages.
